# IA Front — Interface de Chat com Memória

**Autor:** Kaiky Yoshio Ono Marins  
**Categoria:** Python · Streamlit · IA generativa  
**Status:** Protótipo de estudo

## Visão geral

Interface web experimental em Streamlit para conversar com um agente de IA. O código demonstra histórico de mensagens na sessão, apresentação das mensagens em formato de chat e persistência da memória do agente com SQLite.

## Recursos demonstrados

- Interface de conversa com Streamlit.
- Histórico de mensagens durante a sessão.
- Respostas geradas por modelo de linguagem.
- Persistência de contexto usando SQLite.
- Ação para limpar a conversa.

## Tecnologias

- Python
- Streamlit
- Agno
- SQLite
- NVIDIA NIM / endpoint compatível com OpenAI
